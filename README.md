# vcy-platform
掌御手机管理平台

## 概述
该平台是一个专为管理各种型号测试手机而设计的全面解决方案。该平台提供了实时监测、远程控制、数据管理和安全防护等功能，旨在帮助用户高效、便捷地管理和监控测试手机的状态，确保测试过程的顺利进行。

## 功能亮点
* 实时在线监控：平台能够实时监测所有连接的测试手机的在线状态，包括设备的健康状况、电池水平、存储使用情况等，确保设备随时处于可测试状态。

* 远程控制与管理：用户可以远程控制测试手机，执行重启、安装应用、数据备份等操作，无需物理接触设备，大大提升管理效率。

* 多型号设备支持：平台支持各种主流手机型号，包括但不限于iPhone、Samsung、Huawei、Xiaomi等，确保测试覆盖广泛，满足不同需求。

* 设备状态历史记录：平台记录设备的历史状态，包括在线时间、离线原因、测试次数等，帮助用户追踪设备的使用情况，进行数据分析。

* 权限管理与安全防护：提供严格的权限管理机制，确保只有授权用户才能访问和控制设备，同时具备数据加密和防火墙功能，保护设备和数据的安全。

* 易用性与兼容性：界面简洁，操作直观，同时平台兼容Windows、Mac和Linux操作系统，满足不同用户的使用习惯。

## 使用指南
### 系统要求
- 操作系统：Windows 10/11, macOS, Linux
- 内存：4GB以上
- 硬盘空间：至少1GB可用空间
- 网络：稳定的互联网连接
### 部署要求
- Java8 / Redis / Rabbit MQ / Mysql / Kafka
- 数据库相关
-- 数据库管理系统：
当前项目使用了 MySQL 作为数据库，开源前需要确保数据库的使用符合开源协议。如果使用的是开源版本的 MySQL，需要明确版本号以及相关的配置信息。例如，当前项目中使用的 JDBC URL、用户名和密码等敏感信息需要进行妥善处理，建议在开源时将这些信息替换为示例值，并在文档中说明如何根据实际情况进行配置。
考虑到数据迁移和数据备份的问题，需要提供数据库初始化脚本（如 SQL 脚本），方便其他开发者在本地搭建环境时能够快速创建和初始化数据库结构。
-- 数据库连接池：
注意：项目中使用了 HikariCP 作为数据库连接池，开源时需要明确其版本号和配置信息。HikariCP 本身是开源的，但需要确保项目中使用的版本没有兼容性问题。同时，需要在文档中说明如何根据不同的数据库和应用场景对 HikariCP 进行优化配置。
- 缓存相关
-- Redis：
当前项目使用了 Redis 作为缓存，开源前需要确认 Redis 的使用方式和版本。如果使用的是 Redis Sentinel 模式，需要详细说明配置信息，如主节点名称、哨兵节点列表等。
对于 Redis 的访问密码等敏感信息，同样需要进行替换和说明。此外，需要考虑到 Redis 的高可用性和性能优化，例如如何进行 Redis 集群的搭建和配置，以及如何避免缓存雪崩、缓存击穿等问题。
- 消息队列相关
-- Kafka：
项目中启用了 Kafka 日志功能，需要确保 Kafka 的版本和配置信息明确。在开源时，需要说明 Kafka 的集群地址、主题名称等信息，并提供示例代码说明如何进行 Kafka 的生产者和消费者的配置和使用。
考虑到 Kafka 的性能和可靠性，需要在文档中说明如何进行 Kafka 的分区和副本的配置，以及如何处理消息丢失和重复消费的问题。
- 配置中心相关
-- Spring Cloud Config：
项目中使用了 Spring Cloud Config 作为配置中心，需要确保配置中心的服务端和客户端的版本号一致，并且配置中心的服务端能够正常运行。
对于配置中心的配置文件，需要进行清理和整理，移除敏感信息，并在文档中说明如何进行配置中心的搭建和配置。
-- Consul：
项目中使用了 Consul 作为服务发现和配置管理工具，需要确保 Consul 的版本和配置信息明确。在开源时，需要说明 Consul 的集群地址、端口号等信息，并提供示例代码说明如何进行 Consul 的服务注册和发现。
- 认证授权相关
-- OAuth2：
项目中使用了 OAuth2 进行认证授权，需要确保 OAuth2 的配置信息明确，如客户端 ID、客户端密钥、授权服务器地址等。在开源时，需要将这些敏感信息替换为示例值，并在文档中说明如何进行 OAuth2 的配置和使用。
同时，需要考虑到 OAuth2 的安全性问题，如如何防止 CSRF 攻击、如何进行令牌的刷新和过期处理等。
- 日志相关
-- Logback：
项目中使用了 Logback 作为日志框架，需要确保 Logback 的版本和配置信息明确。在开源时，需要提供 Logback 的配置文件，并说明如何进行日志的级别调整和日志文件的存储路径配置。
- 其他中间件
-- MyBatis：
项目中使用了 MyBatis 作为 ORM 框架，需要确保 MyBatis 的版本和配置信息明确。在开源时，需要提供 MyBatis 的配置文件和 Mapper 文件，并说明如何进行 MyBatis 的配置和使用。

## 常见问题与解答
Q: 如何添加新设备？
A: 在主界面点击“添加设备”，根据设备型号选择相应的连接方式，按照指引完成配置。

Q: 平台是否支持批量操作？
A: 是的，平台支持对多台设备进行批量操作，如批量重启、批量安装应用等。

Q: 数据安全如何保证？
A: 平台采用数据加密传输和存储技术，同时具备防火墙防护，有效防止数据泄露和非法访问。

Q: 是否有详细的使用教程？
A: 是的，平台提供详细的使用教程，包括视频教程和文本指南，可在帮助中心获取。
